# 换牌王（Card Exchange）

一个考验**记忆力、观察力与心理博弈**的多人扑克桌游网页版。摸牌、记牌、换牌、弃牌、定牌——总分最小者获胜。

> 🎮 在线试玩：<https://cardexchange.onrender.com/>
> （支持手机浏览器，2~4 人对战 + 机器人）

---

## 玩法简介

每人手牌 4 张，只允许在发牌时看一次自己的牌，之后**全凭记忆**。摸到功能牌可以窥探、换牌，弃掉的高分牌可以被"跟弃"甩锅——但记错牌的人会被罚牌。牌面越小分越少，定牌后比总分，最小者胜。

## 游戏规则

### 道具与人数

- 一副扑克（54 张，含大小王）
- 每局 2~4 人，可添加 1~3 个机器人

### 分数计算

| 牌 | 分数 |
| --- | --- |
| 大王 / 小王 | 0 分 |
| 红桃 K | −1 分 |
| A ~ K（其余花色） | 1 ~ 13 分 |

### 功能牌

| 牌 | 功能 |
| --- | --- |
| 7、8 | 看自己一张牌（限时展示） |
| 9、10 | 看别人一张牌（限时展示） |
| J、Q | 暗换一次：用自己一张牌换别人一张牌 |
| K | 明换一次：看完双方各一张牌后，决定换或不换 |

功能牌可以发挥功能，也可以作为分数牌直接弃掉或替换手牌；无功能的牌只能当作分数牌。

### 流程

1. **发牌**：每人依次摸牌至 4 张。看完自己的 4 张牌后，按固定顺序盖住，之后不可再翻看。
2. **行动**：从一名玩家开始轮流摸牌，摸到的牌可选择发动功能、替换手牌或弃牌。
3. **跟弃**：当一张分数牌被弃掉，手中有相同分数牌的玩家可以跟弃（每轮每人限一张）；多位玩家跟弃时，**速度最快者**成功弃牌，失败者罚补一张牌库剩余的牌。弃牌后不补牌，手牌最少可以为 0。
4. **定牌**：玩家在自己的回合可以宣布定牌。其他玩家按逆时针顺序各操作一轮后（不能再对已定牌玩家换牌），全部展开手牌，**分数总和最小者获胜**；分数并列则同时胜出。
5. **牌堆耗尽**：若牌堆耗尽仍未定牌，手牌总分最低者胜。

### 定牌奖励（可开关）

- 定牌时牌堆剩余 ≥60%：定牌者总分 −2
- 定牌时牌堆剩余 ≥35%：定牌者总分 −1

### 多局积分

支持多局累计积分，每局结束后记录总分，多局后**累计总分最小者**获得最终胜利。

## 功能特性

- 🎮 **联机对战**：WebSocket 实时对战，2~4 位真人玩家，可随时添加机器人
- 🤖 **机器人**：三种难度（新手 / 标准 / 高手），机器人有可配置的"记忆误差"
- 🎓 **教学引导局**：固定剧本 + 步骤提示，新手快速上手
- 👀 **观战模式**：随时进入对局观战，可发送表情/文字与玩家互动
- 💬 **快捷表情**：8 个预设表情/短语，对局中一键发送
- 🖼️ **头像系统**：12 个动物头像 + 自定义上传；选动物头像自动匹配默认昵称
- 🎨 **双主题**：可爱风 / 经典风，一键切换
- ⚙️ **房间设置**：跟弃窗口时长（2/3/4 秒）、定牌奖励开关、是否允许跟弃自己
- 🔄 **托管机制**：玩家退出/掉线后由服务器托管回合，可随时回到对局
- 📱 **移动端适配**：手机浏览器可直接游玩

## 本地运行

要求：Node.js 18+

```bash
# 1. 安装依赖
npm install

# 2. 启动联机服务器（3001 端口，含 WebSocket）
npm run server

# 3. 另开一个终端，启动前端开发服务器（5173 端口）
npm run dev
```

浏览器打开 <http://localhost:5173> 即可开始游戏。

**本机测试联机**：打开两个浏览器标签页访问同一地址，即可扮演两个玩家。

**局域网联机**：电脑与手机连同一 WiFi（或手机开热点），手机访问 `http://<电脑局域网IP>:3001`（需先 `npm run build` 让 3001 提供静态页面）。

## 测试

```bash
npm test          # 运行全部测试（Vitest）
npm run test:watch
```

提交前请确保 `npx vitest run` 全绿、`npm run build` 通过。

## 技术栈

- **前端**：React 18 + TypeScript + Vite 5
- **后端**：Node.js + WebSocket（`ws`），tsx 运行，零框架
- **测试**：Vitest + Testing Library

## 项目结构

```
├── src/            # 前端（React 组件、样式、游戏状态机）
│   ├── core/       # 游戏核心逻辑（发牌、功能牌、跟弃、结算）
│   ├── components/ # 界面组件（大厅、房间、对局、观战）
│   └── styles/     # 主题样式（可爱风 / 经典风）
├── server/         # 联机服务器（房间管理、WebSocket 协议、机器人托管）
├── tests/          # 自动化测试（含游戏规则与服务器协议测试）
├── docs/           # 产品设计文档与技术方案
├── public/         # 静态资源（分享卡片图、favicon）
├── Dockerfile      # 容器化部署
└── render.yaml     # Render 部署配置
```

## 部署

项目已配置 Dockerfile 与 render.yaml，可一键部署到 [Render](https://render.com)：

1. 把仓库推送到 GitHub
2. Render 中新建 Web Service，连接该仓库
3. 使用 `render.yaml` 配置，或手动设置：构建命令 `npm install && npm run build`，启动命令 `npm run server`
